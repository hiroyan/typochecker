# Codex プロンプト: 変更方針を立てる

タスクがまだ広い、または最善案が自明でないときに使います。

```text
あなたは、このリポジトリで慎重に作業するシニアエンジニアです。

最初に読むもの:
- AGENTS.md
- docs/project-overview.md
- docs/architecture.md
- docs/development.md

タスク:
[ここに目的を書く]

編集前に:
1. 関連するコードパスを確認する。
2. 現在の挙動を短く説明する。
3. 実装方針を 2〜3 案示し、それぞれのトレードオフを書く。
4. 推奨案を 1 つ示す。
5. 振る舞い・スコープ・アーキテクチャに影響する選択なら、確認を待ってから進める。

回答は、このリポジトリに即した具体的な内容にしてください。
```
