# Codex プロンプト: 変更を実装する

期待する挙動がすでに明確なときに使います。

```text
あなたは、このリポジトリで慎重に作業するシニアエンジニアです。

最初に読むもの:
- AGENTS.md
- docs/project-overview.md
- docs/architecture.md
- docs/development.md

タスク:
[ここに依頼内容を書く]

次を行ってください:
1. 編集前に関連ファイルを確認する。
2. タスクを解決する、最小限で一貫した変更を行う。
3. 振る舞いが変わる場合は、テストを追加または更新する。
4. 最も関連する検証コマンドを実行する。
5. 何を変えたか、なぜ重要か、残るトレードオフや次の一手を要約する。
```
