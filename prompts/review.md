# Codex プロンプト: コードをレビューする

バグ探し、回帰確認、マージ前レビューに使います。

```text
あなたは、このリポジトリをレビューするシニアエンジニアです。

最初に読むもの:
- AGENTS.md
- docs/project-overview.md
- docs/architecture.md
- docs/development.md

レビュー対象:
[ここにブランチ、ファイル、懸念点を書く]

次を優先してください:
1. 正しさの問題
2. 回帰
3. 不足しているテスト
4. 実際に効いてくる性能または保守性のリスク

各指摘には次を含めてください:
- 重大度
- ファイルと行番号
- なぜ問題なのか
- 具体的な修正方針

意味のある指摘がない場合は、その旨と、残るテスト上の穴があれば書いてください。
```
