# プロジェクト概要

## 目的

Typo Checker は、テキストファイル内の英単語から typo の可能性がある語を見つける
小さな Ruby プログラムです。入力から単語を取り出し、短すぎる語を除外したうえで、
設定された Levenshtein 距離内にある辞書語を候補として提案します。

## 現在できること

- 基本辞書と、任意のキーワード辞書を読み込む
- 辞書語から簡単な語形変化を展開する
  - 過去形
  - 現在進行形
  - 複数形
- テキストから小文字語と一部の大文字トークンを抽出する
- 削除・挿入・置換による候補語を生成する
- typo の可能性がある語と修正候補を表示する
- `typochecker.rb` から CLI として実行できる

## 重要なファイル

| パス | 役割 |
| --- | --- |
| `typochecker.rb` | 実装本体と CLI |
| `words.txt` | 同梱英語辞書 |
| `keyword.txt` | 追加で許可する語 |
| `test/test.txt` | サンプル入力 |
| `test/typocheckerSpec.rb` | 現在の検証スクリプト |

## プロダクトとしての意図

このプロジェクトは、大規模なアプリケーションではなく、意図的に小さなユーティリティです。
発展させるときは、次を優先します。

- 巧妙さより正しさ
- 抽象化の多さより読みやすい Ruby
- 隠れたヒューリスティックより明示的な振る舞い
- 大規模な書き換えより小さな改善の積み重ね

## 気づいておくべき粗さ

- README はまだ最小限です。
- 既存のテストファイルは、厳密な spec というより benchmark / smoke test に近いです。
- CLI とコアロジックが同じファイルにあります。
- Levenshtein 候補生成は、距離が大きくなると計算量が増えます。

これらは、すべての作業で即座に直すべき問題ではありません。
変更時の判断材料として共有しておく文脈です。
