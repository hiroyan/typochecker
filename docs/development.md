# Codex 向け開発ガイド

## 環境

- 言語: Ruby
- 実行時依存: 標準ライブラリのみ
- 現在の検証方法: Ruby スクリプトの直接実行

## よく使うコマンド

```sh
# 現在の smoke test / benchmark スクリプトを実行
ruby test/typocheckerSpec.rb

# 同梱辞書を使ってサンプル入力を CLI で検査
ruby typochecker.rb -d words.txt -k keyword.txt test/test.txt
```

## 編集方針

- タスクで明示されない限り、既存の公開挙動は保つ。
- 大きな抽象化を足すより、小さなヘルパーの抽出を優先する。
- パッケージ化や UX 改善が目的でない限り、簡素な CLI を保つ。
- バグ修正や、単語抽出 / 候補生成の挙動変更では、焦点を絞ったテストを追加する。
- 性能が論点になる場合は、最適化の前に候補数の増え方を観測する。

## 将来の改善候補

以下は今後の候補であり、毎回必ず片づけるべき cleanup ではありません。

1. smoke script を正式な自動テストスイートへ置き換える
2. CLI とライブラリコードを分離する
3. 行番号を 0 始まりにするか 1 始まりにするか明確化する
4. `README.md` に利用例と使い方を追加する
5. 辞書が大きくなる、または既定距離を上げる場合に、より効率的な探索方法を検討する

## Codex タスクの完了条件

通常、完了時には次を含めます。

- 何を変えたかの簡潔な説明
- なぜその変更が必要だったか
- 実行した検証
- 残るトレードオフや、知っておくべき次の一手
